## 🚀 Featured Projects

<details>
<summary><b>🌌 Project AetherDB: High-Performance Distributed Vector Database</b></summary>
<br/>

### Project Description
A lightweight, ultra-fast distributed vector database designed from scratch in C++ for real-time high-dimensional embedding search and clustering.

| Metric | Details |
| :--- | :--- |
| **Stack** | C++20, gRPC, FlatBuffers, CUDA, OpenMP |
| **Scale** | 100M+ high-dimensional vectors with sub-10ms query latency |
| **Performance** | HNSW index traversal optimized with SIMD instructions (AVX-512) |
| **Security** | TLS 1.3 encrypted gRPC transport, RBAC role authorization |
| **Impact** | Improved semantic search pipeline throughput by 4x for a FAANG-scale application |
| **Repository** | [aether-db-core](https://github.com/ismailqureshi72) |

### Professional Project Explanation
AetherDB was conceived to tackle the bottlenecks associated with scaling real-time vector search on heterogeneous hardware. By implementing custom Hierarchical Navigable Small World (HNSW) graph algorithms directly using SIMD compiler intrinsics, the engine achieves near-hardware-limit throughput. The distributed query layer utilizes a decentralized consensus algorithm (Raft) to orchestrate data replication and shard routing across multiple nodes, ensuring high availability and fault-tolerant query execution.
</details>

</details>

<details>
<summary><b>👁️ Project CognitiveVision: Real-Time Edge Video Analytics System</b></summary>
<br/>

### Project Description
A low-latency deep learning solution optimized for multi-object tracking and anomaly detection on edge computing platforms.

| Metric | Details |
| :--- | :--- |
| **Stack** | Python, C++, PyTorch, TensorRT, OpenCV, GStreamer, Docker |
| **Scale** | Concurrent monitoring of 30+ HD 1080p camera streams on single NVIDIA Jetson |
| **Performance** | Sustained 60 FPS object detection utilizing TensorRT quantization (INT8) |
| **Security** | Edge-only data processing minimizing data privacy leaks, encrypted local storage |
| **Impact** | Cut processing hardware cost by 60% via optimized model quantization and pipeline parallelization |
| **Repository** | [cognitive-vision-edge](https://github.com/ismailqureshi72) |

### Professional Project Explanation
CognitiveVision combines advanced deep learning object detection (YOLOv8) with lightweight C++ tracking filters (DeepSORT). To operate in resource-constrained environments, the PyTorch model is converted to ONNX and compiled into an optimized TensorRT engine with INT8 calibration. Frame ingestion is managed by a GStreamer pipeline, which feeds decoded video frames directly to GPU memory, bypassing CPU bottlenecks and drastically reducing processing latency.
</details>
